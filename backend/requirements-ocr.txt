# GradeMIND — optional handwriting-OCR engine profile.
#
# The core app (requirements.txt) works fully without this file: Tesseract
# (pytesseract + the system tesseract-ocr binary) provides baseline OCR, and
# grading itself needs no OCR engine at all beyond extracted text.
#
# Install these on top of requirements.txt to enable the higher-accuracy
# multi-engine voting/router pipeline (EasyOCR, PaddleOCR, TrOCR) used for
# handwritten answer sheets:
#
#   pip install -r requirements.txt -r requirements-ocr.txt
#
# These pull in PyTorch and will download model weights on first use
# (TrOCR ~1.3GB from HuggingFace on first run). See backend/README.md for
# details, including running this profile in Docker.

paddleocr>=2.7.0
paddlepaddle>=2.5.0
torch>=2.1.0
